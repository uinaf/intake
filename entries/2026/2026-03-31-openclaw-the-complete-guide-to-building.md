A long-form Lenny's Newsletter guest post by Claire Vo on what OpenClaw is, how to set it up safely, and which recurring automations make it useful in practice.

## Key takeaways

- **Positioning**: A persistent, message-driven personal assistant that runs on an owned machine, uses tools, skills, and cron, and can operate across Telegram, WhatsApp, and Slack.
- **Isolated setup**: Start on an isolated machine rather than a daily personal or work computer; suggested paths are hosted offerings, a VPS, or a dedicated Mac Mini.
- **Onboarding**: Telegram is presented as the easiest beginner channel; recommended starter skills include `gog` and `summarize`.
- **Mental model**: A gateway receives messages; agents sit behind it with identities, workspaces, and tools; markdown files such as `AGENTS.md`, `SOUL.md`, `IDENTITY.md`, `TOOLS.md`, and `USER.md` shape behavior.
- **Recurring ops**: Practical uses include family coordination, sales triage, content workflows, meeting briefs, support-ticket-to-docs loops, and launch or task management.
- **Tone**: Enthusiastic and mainstreaming; it sells an AI-manager-with-a-team framing more than low-level implementation detail.
- **Claims to check**: It recommends Claude Opus 4.6 or Codex 5.4, mentions unverified Anthropic account-reuse rumors, and describes 30-minute heartbeats plus a cron-driven model.
