Drop-in universal memory layer that handles cross-session retention without custom harness-level state management code.

## Key takeaways

- **Drop-in memory**: Handles cross-session retention without custom harness-level state management code.
- **AWS exclusive provider**: YC-backed, and the AWS Agent SDK's exclusive memory provider.
- **Low integration cost**: Lowest integration cost for production-grade persistent memory.
