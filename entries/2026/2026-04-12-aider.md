Aider is an AI pair-programmer harness with an Architect mode that splits planning and coding across models, and uses git as the undo mechanism.

## Key takeaways

- **Architect mode**: Planning runs on one LLM and coding on another.
- **Git as undo**: Version control is the rollback mechanism instead of a custom state system.
- **Reference value**: The note treats it as the best reference for multi-file editing tool design and planner/coder layer separation.
