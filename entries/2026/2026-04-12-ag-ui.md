AG-UI covers the live boundary between an agent and a user-facing app: standard execution events that frontends consume over SSE, WebSockets, or webhooks.

## Key takeaways

- **Missing layer**: It fills a gap neither MCP nor A2A covers well—the live boundary between an agent and a user-facing application.
- **Event model**: Agents emit standard execution events; applications consume them over SSE, WebSockets, or webhooks.
- **More than tokens**: The protocol standardizes state updates, tool rendering, and interrupts during execution, not just streamed text.
- **Complementary stack**: MCP gives agents tools, A2A lets agents talk to agents, and AG-UI brings agents into product interfaces.
