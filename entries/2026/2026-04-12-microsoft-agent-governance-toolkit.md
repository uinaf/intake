Seven-package, multi-language runtime security toolkit that addresses all 10 OWASP Agentic AI risks with deterministic, sub-millisecond policy enforcement.

## Key takeaways

- **OWASP coverage**: Addresses all 10 OWASP Agentic AI risks with deterministic, sub-millisecond policy enforcement.
- **Multi-language packages**: Seven packages across Python, Rust, TypeScript, Go, and .NET.
- **Runtime components**: Includes Agent OS (policy engine intercepting every action), Agent Mesh (secure agent-to-agent communication), and Agent Runtime (dynamic execution rings).
- **Framework hooks**: Hooks into LangChain callbacks, CrewAI task decorators, Google ADK plugins, and Microsoft Agent Framework middleware.
