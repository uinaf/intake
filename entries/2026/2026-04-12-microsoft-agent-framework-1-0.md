Production-ready 1.0 release unifying Semantic Kernel and AutoGen into a single framework with graph orchestration, middleware, and declarative YAML agent definitions.

## Key takeaways

- **Unified 1.0**: April 2026 1.0 release unifying Semantic Kernel and AutoGen into a single framework.
- **Graph and middleware**: Graph-based orchestration, a middleware pipeline for intercepting every execution stage, and declarative YAML agent definitions.
- **DevUI debugger**: Browser-based debugger for visualizing agent execution, message flows, and tool calls in real time.
- **Enterprise coverage**: Multi-provider support (Azure OpenAI, Anthropic, Bedrock, Gemini, Ollama) with A2A and MCP integration for .NET and Python.
