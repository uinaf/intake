## Why it matters
Production-ready 1.0 release (April 2026) unifying Semantic Kernel and AutoGen into a single framework with graph-based orchestration, middleware pipeline for intercepting every execution stage, and declarative YAML agent definitions. DevUI provides a browser-based debugger for visualizing agent execution, message flows, and tool calls in real time. Multi-provider support (Azure OpenAI, Anthropic, Bedrock, Gemini, Ollama) with A2A and MCP integration makes this the most complete enterprise agent harness framework available for .NET and Python.
