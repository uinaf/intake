Simon Willison: build a personal library of working code, not just theoretical knowledge. Knowing something is possible is not the same as having seen it run.

## Key takeaways

- **Working proofs**: Collect proof-of-concepts, snippets, and single-file HTML tools.
- **Recombination**: Feed an agent two or more working examples and ask it to merge them.
- **Example**: Tesseract.js plus PDF.js prompted Claude 3 Opus into a working PDF OCR tool in minutes.
- **Repos as reference**: Point agents at your own repos, clone to `/tmp`, or curl public tools.
- **Document once**: "We only ever need to figure out a useful trick once" if it is documented with working code.
