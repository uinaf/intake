An open-source LLM and agent eval framework with 20+ built-in metrics, pytest integration, and a CI-friendly runner.

## Key takeaways

- **Built-in metrics**: More than 20 metrics including hallucination, answer relevancy, RAGAs, and tool correctness.
- **pytest and CI**: pytest integration and a CI-friendly runner.
- **Skip hand-rolls**: Removes the need to hand-roll eval infrastructure for structured, repeatable agent quality gates.
