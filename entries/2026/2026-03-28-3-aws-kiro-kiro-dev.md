Kiro is an AWS-backed VS Code fork that treats spec-driven development as a first-class IDE workflow rather than an add-on.

## Key takeaways

- **Executable specs**: Requirements, design, and tasks are defined before code, with user stories, technical design, and trackable implementation tasks.
- **Agent hooks**: Agents can trigger on events such as file save to generate docs, tests, or optimizations.
- **Steering and autopilot**: Steering files set project standards. Autopilot mode runs large tasks autonomously.
- **Tradeoffs**: Deep IDE integration and polished UX come with lock-in to the Kiro IDE, Claude models, and the AWS ecosystem.
