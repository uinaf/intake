Louis-François Bouchard argues that many agent failures are harness failures: the same model can claim success without tests, or improve a lot when tools, retries, and guardrails change.

## Key takeaways

- **False success**: A coding agent left in a loose loop can claim success without even running tests.
- **Car metaphor**: The model is the engine, context is the fuel, and the harness is the rest of the car.
- **Harness levers**: Better tools, permissions, tests, retries, and guardrails can change outcomes dramatically without changing the underlying model.
- **Self-reflection**: After each interaction the agent updates its own skill file from edits, failures, and preferences.
- **Claimed results**: Lower token usage, better output quality, and compounding improvement from harness feedback.
