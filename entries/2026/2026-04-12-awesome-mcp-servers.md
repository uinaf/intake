An index of hundreds of MCP servers across roughly 30 categories — filesystems,
databases, cloud storage, version control, communication platforms, workflow
automation, finance, research data, code execution — marking official
implementations and listing competing implementations of the same integration.

Two things make it more useful than the average list: it names which clients each
server is known to work with (Claude Desktop, VS Code, Cursor, Zed), and it warns
about sandboxing risk for servers that execute code.

Note the repository was archived on 2026-08-01 and is read-only, so it is a
snapshot of the ecosystem rather than a live directory.
