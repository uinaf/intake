An index of hundreds of MCP servers across about 30 categories, marking official implementations and listing competing ones for the same integration.

## Key takeaways

- **Category coverage**: Filesystems, databases, cloud storage, version control, communication, workflow automation, finance, research data, and code execution.
- **Client compatibility**: Names which clients each server is known to work with, including Claude Desktop, VS Code, Cursor, and Zed.
- **Sandboxing risk**: Warns about sandboxing risk for servers that execute code.
- **Archived snapshot**: The repository was archived on 2026-08-01 and is read-only, so it is a snapshot rather than a live directory.
