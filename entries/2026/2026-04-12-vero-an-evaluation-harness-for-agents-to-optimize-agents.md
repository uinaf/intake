Section: Evals & Verification

Framework for evaluating agent-on-agent optimization cycles: a coding agent iteratively modifies a target agent's harness (prompts, tools, configuration) through edit-execute-evaluate loops while VeRO captures versioned agent snapshots, budget-controlled evaluation, and structured execution traces. Addresses the meta-evaluation gap — how to systematically measure whether one agent is improving another — with reproducible infrastructure and a benchmark suite for comparing optimizer configurations.
