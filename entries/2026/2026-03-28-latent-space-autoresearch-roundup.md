# Latent Space Autoresearch Roundup

Comprehensive ecosystem update. Key highlights:

## Autoresearch
- 700 changes, 20 transferable improvements, 11% speedup
- Agent loops are fragile — heavily dependent on harness/infra, not model quality
- GPT-5.4 struggles with continuous looping that Opus 4.6 handles well
- Robust looping primitives and interruption handling are critical

## Code Review Evolution
- Anthropic code-review plugin: 16% → 54% of PRs with meaningful comments, <1% false positives
- Multi-agent parallel review with confidence-based false positive filtering
- OpenAI and Cognition launched free PR review tools with autofix

## Key Insight
- "Vibe training" (Yi Tay, Dec 2025): AI systems autonomously debug and improve code, sometimes outperforming creators
- Bottleneck shifted from implementation to review, verification, and governance
- Users mixing models by role (planner, doer, editor) rather than seeking one best model

## Infrastructure
- "Turn everything into an environment" is the democratization play
- Document context evolving from general frameworks to deep infra
- Evaluation and security testing moving earlier in development (shift-left)
