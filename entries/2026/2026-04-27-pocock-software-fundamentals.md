Matt Pocock's AI Engineer Europe 2026 talk: code is not cheap. Unguided specs-to-code degrades across iterations, so software fundamentals matter more in the AI era, not less.

## Key takeaways

- **Entropy machine**: Specs-to-code can look fine on pass one and turn to garbage by pass three because it removes the feedback that catches complexity.
- **Shared design concept**: Without Brooks' invisible design concept, the model cannot do what you want. The "Grill Me" prompt forces 40–100 questions first.
- **Shared vocabulary**: Ubiquitous language cuts verbosity. A glossary skill beats hoping the model guesses your terms.
- **Feedback speed limit**: Types, tests, and small deliberate steps are the rate limiter. TDD enforces that loop.
- **Deep modules**: Ousterhout's deep modules hide complexity behind simple interfaces. Shallow modules lose the agent in the mess.
- **Expensive bad code**: A hard-to-change codebase blocks the bounty AI can offer. Bad code is more expensive than ever.
