Karpathy frames the shift as software 3.0: LLMs act as a new programmable computer, and the prompt/context window is the interface. Agentic tools crossed a threshold where generated chunks often just work.

## Key takeaways

- **Software 3.0**: LLMs behave like programmable computers; prompts and context are the new interface layer.
- **New surfaces**: The jump is not only productivity. Entirely new product surfaces become viable as old app logic collapses into model calls.
- **Verifiable domains**: Capability compounds fastest where outputs can be checked and rewarded, which is why code and math moved first.
- **Startup terrain**: Look for valuable, checkable tasks with underdeveloped RL or eval loops that labs have not already optimized.
- **Jagged models**: The same systems can refactor large codebases or find vulnerabilities and still fail simple common-sense prompts.
- **Two modes**: Vibe coding raises the floor for creators; agentic engineering keeps professional quality, security, architecture, taste, and oversight.
- **Human up-stack**: Specification, system design, judgment, review, and knowing which details matter. You can outsource thinking, not understanding.
- **Agent-native infra**: Tools, APIs, docs, and systems should treat agents as first-class users. They become the sensors and actuators across software.
