OCI-container sandboxes with sub-90ms startup, built-in Git operations, LSP support, and indefinite state persistence.

## Key takeaways

- **Fast containers**: OCI-container sandboxes with sub-90ms startup.
- **Dev tooling**: Built-in Git operations and LSP support.
- **Long-lived directories**: Indefinite state persistence for harnesses that need working directories across sessions, complementing E2B's ephemeral execution.
