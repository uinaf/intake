Addy Osmani and Hassan Djirdeh's ~200-page book: product engineering is an engineer-PM-designer hybrid focused on outcomes. AI moves the bottleneck from writing code to writing specs and reviewing output.

## Key takeaways

- **Spec as product**: The spec becomes the product; code becomes the artifact.
- **Role shift**: Engineers orchestrate and validate; PMs form intent agents can execute; some orgs have PMs own prompts.
- **Agent stack**: Traditional AI to RAG to agents to MCP/A2A; MCP collapses the N-by-M tool integration problem.
- **RAG goal**: Most RAG is primitive chunking; the goal is enabling decisions, not answering questions.
- **Prompt patterns**: Chain-of-thought, few-shot, persistent project rules, constraint stuffing, confidence checks; treat prompts as versioned artifacts.
- **Workflow stats**: 97% of developers have used AI tools; 40% of checked-in code is AI-generated and unmodified (Morgan Stanley).
- **Future**: Code becomes more disposable; maintain specs, not implementations; adaptability is the meta-skill.
