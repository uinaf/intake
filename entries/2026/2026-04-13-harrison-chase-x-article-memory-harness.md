Harrison Chase argues that harnesses are the lasting scaffolding for serious agents, and that memory is inseparable from them. Closed harnesses turn memory into lock-in.

## Key takeaways

- **Harness stays**: Agent harnesses remain the dominant scaffolding even as models improve.
- **Memory coupling**: The harness decides how context is loaded, compacted, persisted, exposed, and queried.
- **Harness responsibilities**: Short-term and long-term memory, system instructions, skills, working-directory exposure, and compaction are not bolt-ons.
- **Ownership risk**: If the harness is closed behind a proprietary API, you do not really own the agent's memory.
- **Switching cost**: Stateless model APIs are easy to swap; memory and orchestration inside a provider's system are not.
- **Open prescription**: Open harnesses plus open memory infrastructure keep model optionality.
- **Product pitch**: The piece also sells LangChain Deep Agents as open, model-agnostic, and able to plug into external memory stores.
