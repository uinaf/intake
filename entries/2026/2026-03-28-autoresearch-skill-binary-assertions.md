A video shows two autoresearch layers on Claude Code skills: trigger-description tuning, then output improvement against binary yes/no assertions.

## Key takeaways

- **Description loop**: Adjust the skill description, test whether it triggers correctly, and keep or discard.
- **Binary assertions**: Evaluate output with yes/no checks, not 1-10 ratings. A LinkedIn-post skill went from failing to passing in two iterations.
- **Noise reduction**: Binary checks make the loop more deterministic. Tone, creativity, and context still need a human.
- **Never-stop instruction**: Once the experiment loop has begun, the agent is told not to pause.
