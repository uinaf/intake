OpenSpec is a lightweight spec framework for AI coding assistants: SHALL/MUST/SHOULD requirements plus GIVEN/WHEN/THEN scenarios, one folder per change.

## Key takeaways

- **Change folders**: Each change gets proposal, specs, design, and tasks; spec deltas show behavioral diffs in PRs.
- **Workflow**: `/opsx:propose` to implement to archive, with parallel changes and lite versus full rigor.
- **Integrations**: More than 20 AI tool integrations.
- **Verdict**: Strong design; overkill for a solo workflow, worth revisiting at team scale.
