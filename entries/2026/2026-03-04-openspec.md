# OpenSpec — Spec-Driven Development

- **URL:** https://openspec.dev
- **Repo:** https://github.com/Fission-AI/OpenSpec
- Type: research
- Tags: spec-driven-development, requirements, given-when-then, tooling, ai-engineering
- **What:** Lightweight spec framework for AI coding assistants. Structured requirements (SHALL/MUST/SHOULD) + GIVEN/WHEN/THEN scenarios. Each change gets its own folder with proposal, specs, design, tasks. Spec deltas show behavioral diffs in PRs.
- **Key features:** `/opsx:propose` → implement → archive workflow, parallel changes, progressive rigor (lite vs full specs), 20+ AI tool integrations
- **Verdict:** Great design and conventions. Overkill for our solo workflow — papyrus-maximus covers our needs. Worth revisiting if projects grow to team scale or need formal behavioral specs.
