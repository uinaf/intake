Kai compares four open-source AI products—Goose, Jan, MoneyPrinterTurbo, and DeepSeek Harness—by asking what subscription layer each can replace. The recurring answer is that open-source software removes rent on the wrapper, not necessarily inference, hardware, or setup costs.

## Key takeaways

- **Goose**: The Linux Foundation's extensible desktop, CLI, and API agent can replace a proprietary agent wrapper while supporting many model providers and MCP tools, but cloud inference still requires a subscription or paid API.
- **Jan**: Jan most directly replaces a hosted chat subscription by running models offline and exposing an OpenAI-compatible local endpoint, although useful performance still depends on capable hardware and memory bandwidth.
- **MoneyPrinterTurbo**: Its script-to-stock-footage pipeline can consolidate several short-form video tools, but paid APIs may remain and keyword retrieval can produce semantically unrelated visuals for specialized topics.
- **DeepSeek Harness**: DeepSeek's MIT-licensed coding harness makes models, tools, skills, sessions, sandboxes, and loops replaceable through plugins, giving developers ownership of the orchestration layer rather than proving superior task completion.
- **Preview risk**: DeepSeek Harness is explicitly a developer preview with expected breaking changes, and its architecture is powered by Cordis—not “Cortis,” as the narration states.
- **Free plumbing**: Open source can eliminate a SaaS markup or proprietary control plane, but users still pay through model tokens, local compute, operational effort, or some combination of the three.
- **Selection rule**: Choose by the layer being replaced—agent loop, private local chat, media automation, or coding harness—and benchmark the complete workflow before cancelling the paid product.
