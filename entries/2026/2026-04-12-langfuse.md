The most widely adopted self-hostable LLM observability platform: traces every agent step, manages prompt versions, and runs evals in one tool.

## Key takeaways

- **Self-hostable observability**: Widely adopted self-hostable LLM observability that traces every agent step, manages prompt versions, and runs evals in one tool.
- **Unified agent traces**: Traces every agent step in the same tool as prompt versions and evals.
- **Prompts and evals**: Manages prompt versions and runs evals alongside tracing.
- **Data residency**: Preferred over cloud-only alternatives when data residency or cost control is a constraint.
