A purpose-built agent memory store with automatic conversation summarization, entity extraction, and semantic search over session history. It handles long-session overflow at the memory layer.

## Key takeaways

- **Memory store**: Built for agent session history rather than generic chat logs.
- **Automatic distillation**: Summarization, entity extraction, and semantic search over that history.
- **Overflow offload**: Solves long-session context overflow in memory instead of forcing the harness to trim by hand.
