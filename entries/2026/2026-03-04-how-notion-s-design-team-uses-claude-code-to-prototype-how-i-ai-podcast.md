Brian Lovin: Notion's design team prototypes in a shared Next.js Prototype Playground with Claude Code. When Claude asks you to do something, teach it to do it itself.

## Key takeaways

- **Playground repo**: Shared Next.js Prototype Playground for the design team.
- **Golden rule**: When Claude asks you to do something, teach it to do it itself.
- **Slash commands**: `/create-prototype`, `/figma` with an MCP verification loop, `/deploy` with CI monitoring.
- **Skills**: Recurring pain like icon hallucination becomes a synonym-search script.
- **Figma still**: Figma is still 60-70%, but AI products need code-first prototyping with real models.
- **Stack**: Claude Code plus Opus 4.5 in the terminal.
