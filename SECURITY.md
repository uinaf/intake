# Security

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/uinaf/intake/security/advisories/new)
or email [dev@uinaf.dev](mailto:dev@uinaf.dev).

Do not disclose credentials, private source material, personal data, or exploit
details in public issues, pull requests, entries, logs, or screenshots. Prefer
a synthetic reproduction and include only the minimum information needed.
